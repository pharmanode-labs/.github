# PharmaNode

**Architecting compliant, high-concurrency infrastructure for the life sciences industry.**

PharmaNode builds open-source and enterprise-grade microservices, adapters, and SDKs designed specifically for the rigorous regulatory and data environments of the pharmaceutical domain. 

## Our Engineering Philosophy
We believe that compliance (HIPAA, GDPR, SOC2, 21 CFR Part 11) should be built into the infrastructure layer, not bolted onto application logic. 
*   **Strict Boundaries:** Built on Hexagonal Architecture principles.
*   **Performance:** Core services written in Go for maximum concurrency and minimal footprint.
*   **Cloud-Native:** Designed for seamless deployment on AWS (EKS, ECS, Serverless) with zero-ETL data flows in mind.

## Core Nodes (Repositories)
*   🚧 `audit-trail-go` - (In Development) A drop-in Go SDK for 21 CFR Part 11 compliant database auditing.
*   🚧 `phi-masking-sidecar` - (In Development) A lightweight proxy for real-time PII/PHI redaction.
